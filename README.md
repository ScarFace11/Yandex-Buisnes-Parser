# 🔍 Yandex Maps Parser + VK Sender

Веб-приложение для автоматического парсинга бизнесов с Яндекс.Карт и рассылки сообщений ВКонтакте.

---

## 📋 Возможности

| Функция | Описание |
|---------|----------|
| 🔍 **Поиск бизнесов** | По запросу и городу с поддержкой сетки координат |
| 📋 **Сбор данных** | Название, адрес, телефон, рейтинг, отзывы, соцсети |
| 📤 **Экспорт** | JSON, Excel (с форматированием и легендой), CSV |
| 🗺 **HTML-карта** | Интерактивная карта с кластеризацией маркеров |
| 💬 **VK-рассылка** | Автоматическая отправка с шаблонами сообщений |
| ⏸️ **Checkpoint** | Возобновление прерванного парсинга |
| 🌐 **Веб-интерфейс** | Управление запуском, просмотр логов и результатов |

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/ScarFace11/Yandex-Buisnes-Parser.git
cd yandex-maps-parser
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка API-ключа Яндекс

```bash
# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env
```

Откройте файл `.env` и вставьте ваш API-ключ:

```
YANDEX_API_KEY=ваш_ключ_сюда
```

> 🔑 Получить ключ можно на [Yandex Cloud Developer](https://developer.tech.yandex.ru/)

### 4. Запуск

```bash
python app.py
```

Откройте браузер: **http://localhost:5000**

## ⚙️ Конфигурация

Основные настройки — в файле `config.py`:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `SEARCH_QUERIES` | `["Автосервисы", "шиномонтаж"]` | Поисковые запросы (массив) |
| `CITY` | `"Ярославль"` | Город поиска |
| `MAX_PAGES` | `1` | Страниц результатов (50 позиций каждая) |
| `USE_GRID` | `False` | Покрытие сеткой координат |
| `GRID_RADIUS_KM` | `20` | Радиус сетки от центра города |
| `GRID_STEP_KM` | `5` | Шаг сетки |
| `FETCH_DETAIL` | `True` | Загружать карточку бизнеса |
| `VALIDATE_SOCIALS` | `False` | Проверять доступность ссылок |
| `MIN_RATING` | `0.0` | Минимальный рейтинг (0 = без фильтра) |
| `MIN_REVIEWS` | `0` | Минимум отзывов (0 = без фильтра) |
| `MAX_WORKERS` | `20` | Параллельных потоков для загрузки деталей |
| `OUTPUT_EXCEL` | `True` | Экспорт в Excel |
| `OUTPUT_JSON` | `True` | Экспорт в JSON |
| `OUTPUT_MAP` | `True` | HTML-карта |
| `OUTPUT_CSV` | `False` | Экспорт в CSV |
| `APPEND_MODE` | `False` | Дозапись в существующий файл |
| `RESUME_MODE` | `False` | Продолжение с checkpoint |
| `PROXIES` | `[]` | Список прокси для ротации |

## 💬 VK-рассылка

1. Получите токен ВКонтакте с правами `messages` и `offline`.
2. В веб-интерфейсе перейдите на вкладку **Рассылка**.
3. Вставьте токен и выберите Excel-файл с результатами парсинга.
4. Настройте шаблон сообщения (используйте `{название_бизнеса}` для подстановки имени).
5. Запустите рассылку.

> ⚠️ **Важно:** Токен VK хранится только в браузере и не записывается на диск. При обновлении страницы токен нужно ввести заново.

### Настройки рассылки

| Параметр | Описание |
|----------|----------|
| `message` | Шаблон сообщения |
| `delayMin` | Минимальная задержка между отправками (сек) |
| `delayMax` | Максимальная задержка (сек) |
| `limitType` | `"all"` — все записи, `"count"` — до N отправленных |
| `limitN` | Лимит отправленных сообщений (при `limitType=count`) |

## 📁 Структура проекта

```
├── app.py                          # Flask-приложение (веб-интерфейс)
├── config.py                       # Конфигурация парсера
├── requirements.txt                # Зависимости Python
├── .env.example                    # Пример .env файла
├── sender_config.json.example      # Пример настроек рассылки
│
├── yandex_maps_parser/             # Модуль парсера
│   ├── __init__.py
│   ├── state.py                    # Мутабельное состояние и логирование
│   ├── runner.py                   # Точки входа run() / run_web()
│   ├── search.py                   # Поиск на Яндекс.Картах
│   ├── enrichment.py               # Извлечение деталей бизнеса
│   ├── extractors.py               # Парсинг HTML-карточек
│   ├── exporters.py                # Экспорт в CSV / JSON / Excel / карту
│   ├── geocoding.py                # Геокодинг и построение сетки
│   ├── http_client.py              # HTTP-клиент с ротацией прокси
│   ├── checkpoint.py               # Checkpoint / Resume
│   ├── constants.py                # Константы и шаблоны
│   └── stats.py                    # Статистика в консоли
│
├── vk_sender/                      # Модуль VK-рассылки
│   ├── __init__.py
│   ├── runner.py                   # run_send()
│   ├── vk_adapter.py               # VK API
│   ├── excel_manager.py            # Чтение/запись Excel
│   └── base_adapter.py            # Абстрактный базовый класс
│
├── templates/
│   └── index.html                  # Веб-интерфейс
│
└── output/                         # Результаты парсинга (в .gitignore)
```



## 🐛 Известные ограничения

- Рассылка работает только с ВКонтакте (в планах — другие соцсети).
- Капча Яндекса может заблокировать парсинг при большом объёме запросов.
- Прокси-ротация опциональна, но рекомендуется для больших объёмов.
