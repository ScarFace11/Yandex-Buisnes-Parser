# 🔍 Yandex Maps Parser + VK Sender v2.1.0

Веб-приложение для автоматического парсинга бизнесов с Яндекс.Карт и рассылки сообщений ВКонтакте.

---

## 📋 Возможности

| Функция | Описание |
|---------|----------|
| 🔍 **Поиск бизнесов** | По запросу и городу с поддержкой сетки координат |
| 🏙 **Multi-city** | Поиск по нескольким городам последовательно |
| 📋 **Сбор данных** | Название, адрес, телефон, рейтинг, отзывы, соцсети |
| 📱 **Фильтр соцсетей** | Режим «Все / С соцсетями / Без соцсетей» + AND-фильтр по конкретным сетям |
| 📤 **Экспорт** | Excel (с форматированием), CSV, JSON |
| 🗺 **HTML-карта** | Интерактивная карта с маркерами из всех городов |
| 💬 **VK-рассылка** | Автоматическая отправка с шаблонами сообщений |
| 🔔 **Уведомления** | Browser notifications + звук при завершении |
| 🔄 **Очередь поисков** | Параллельные запуски в изолированных процессах |
| 🔄 **Отслеживание версий** | Автопроверка обновлений на GitHub |
| ⏸️ **Checkpoint** | Возобновление прерванного парсинга |
| 🌐 **Веб-интерфейс** | Управление запуском, просмотр логов и результатов |

## 🚀 Быстрая установка

### Вариант 1: Автоматическая установка (рекомендуется)

**Windows:**
```bash
git clone https://github.com/ScarFace11/Yandex-Buisnes-Parser.git
cd Yandex-Buisnes-Parser
setup.bat
```

**Linux / macOS:**
```bash
git clone https://github.com/ScarFace11/Yandex-Buisnes-Parser.git
cd Yandex-Buisnes-Parser
chmod +x setup.sh && ./setup.sh
```

Скрипт автоматически:
- Создаст виртуальное окружение
- Установит все зависимости
- Запустит сервер

### Вариант 2: Ручная установка

```bash
git clone https://github.com/ScarFace11/Yandex-Buisnes-Parser.git
cd Yandex-Buisnes-Parser

# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/macOS)
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python app.py
```

Откройте браузер: **http://localhost:5000**

### API-ключ

API-ключ Яндекса можно ввести прямо через веб-интерфейс:
1. Откройте **Дополнительные настройки**
2. Вставьте ключ в поле «API-ключ Яндекса»
3. Нажмите **💾 Сохранить** — ключ запишется в `.env`

Или создайте файл `.env` вручную:
```
YANDEX_API_KEY=ваш_ключ_сюда
```

> 🔑 Получить ключ можно на [Yandex Cloud Developer](https://developer.tech.yandex.ru/)

## ⚙️ Конфигурация

Основные настройки — в файле `config.py`:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `APP_VERSION` | `"2.1.0"` | Текущая версия приложения |
| `SEARCH_QUERIES` | `["Автосервисы", "шиномонтаж"]` | Поисковые запросы |
| `MAX_PAGES` | `1` | Страниц результатов (×50 позиций) |
| `USE_GRID` | `False` | Покрытие сеткой координат |
| `GRID_RADIUS_KM` | `20` | Радиус сетки от центра |
| `GRID_STEP_KM` | `5` | Шаг сетки |
| `FETCH_DETAIL` | `True` | Загружать карточку бизнеса |
| `VALIDATE_SOCIALS` | `False` | Проверять доступность ссылок |
| `MIN_RATING` | `0.0` | Минимальный рейтинг |
| `MIN_REVIEWS` | `0` | Минимум отзывов |
| `MAX_WORKERS` | `20` | Параллельных потоков |
| `OUTPUT_EXCEL` | `True` | Экспорт в Excel |
| `OUTPUT_JSON` | `True` | Экспорт в JSON |
| `OUTPUT_CSV` | `False` | Экспорт в CSV |
| `OUTPUT_MAP` | `True` | HTML-карта |
| `PROXIES` | `[]` | Прокси для ротации |

> ⚠️ Все настройки также доступны через веб-интерфейс в «Дополнительные настройки».

## 🏙 Multi-city поиск

В поле «Где ищем?» можно указать несколько городов:

1. Начните вводить название города — появится выпадающий список с населением
2. Выберите город кликом или Enter
3. Поле очистится — добавьте следующий город
4. Нажмите «Найти компании»

**Как работает:**
- Города обрабатываются последовательно
- При завершении каждого города — звуковое уведомление + файл сохраняется
- Каждый город получает отдельный Excel/CSV файл
- Карта и статистика объединяют результаты всех городов

---

## 📱 Режимы поиска

| Режим | Описание | Скорость |
|-------|----------|----------|
| 🌐 **Все** | Все найденные бизнесы без сайта | Обычная |
| 📱 **С соцсетями** | Только с найденными VK/IG/TG и т.д. | Обычная |
| 🚫 **Без соцсетей** | Только без соцсетей | **~10× быстрее** |

При выборе «📱 С соцсетями» появляются **чекбоксы** для выбора конкретных соцсетей.
Логика AND: если отмечены VK + TG, покажет только бизнесы, у которых есть **И** VK, **И** TG.

## 💬 VK-рассылка

1. Получите токен ВКонтакте с правами `messages` и `offline`.
2. Перейдите на вкладку **Отправить в VK**.
3. Вставьте токен и выберите Excel-файл с результатами.
4. Настройте шаблон сообщения (`{название_бизнеса}` подставит имя).
5. Запустите рассылку.

> ⚠️ Токен VK хранится только в браузере и не записывается на диск.

---

## 🔄 Параллельные поиски

- Если запустить новый поиск во время текущего — он встанет в **очередь**
- Когда текущий завершится — следующий стартует автоматически
- Несколько вкладок браузера — общий пул процессов
- Каждый поиск работает в **изолированном процессе** (multiprocessing)

## 🐛 Известные ограничения

- Рассылка работает только с ВКонтакте (в планах — другие соцсети).
- Капча Яндекса может заблокировать парсинг при большом объёме запросов.
- Прокси-ротация опциональна, но рекомендуется для больших объёмов.
- Python 3.11+ (используется `dict | None` type hint syntax).
