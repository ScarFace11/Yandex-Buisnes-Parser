Шаблоны сообщений

Создавайте шаблоны с переменными. При клике на соцсеть в таблице — текст подставится автоматически. Шаблоны общие для команды и хранятся на сервере.

Порядок работы: создайте шаблон для нужной соцсети → выберите его в списке «Шаблон» над таблицей → кликните по значку соцсети у компании. Текст с подставленными данными скопируется в буфер — вставьте его в открытый чат (Ctrl+V).

Настройка Excel-выгрузки

Отметьте столбцы, которые попадут в итоговый Excel-файл. Скрытые столбцы не записываются в файл. Выбор сохраняется автоматически между запусками.

Столбец «Сайт» больше не выгружается — в него попадали служебные ссылки со страниц 2ГИС. Ссылка на карточку подставляется по источнику: для 2ГИС это «2ГИС», для Яндекса — «Яндекс.Карты» (пустого столбца-двойника в файле нет).

Данные

Отметки «Просмотрено» и настройки (включая шаблоны) хранятся рядом с результатами. Экспорт — запасная копия или перенос на другую машину; импорт добавляет отметки из архива, не стирая сделанные после экспорта.

Автокопия отметок пишется ежедневно в output/_backup/ (хранятся 7 дней).
