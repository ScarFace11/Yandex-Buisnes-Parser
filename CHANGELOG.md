# Changelog

Все заметные изменения проекта. Формат — по версиям, свежие сверху.
Версия текущей сборки видна в шапке приложения (`config.APP_VERSION`).

## [2.3.1] — Исправлено авто-обновление и стабильность

**Авто-обновление работает корректно.** Раньше, пока новый релиз был
черновиком, кнопка «Обновить сейчас» скачивала и ставила **предыдущую**
версию (ссылка `releases/latest` не видит черновики), а при неудачной замене
файлов приложение могло молча остаться на старой версии. Теперь адрес
сборки берётся из API опубликованного релиза, версия внутри скачанного
архива сверяется с ожидаемой (устаревший архив отвергается с понятной
ошибкой), замена файлов идёт с ожиданием выхода приложения, повторами при
блокировках и автоматическим откатом при любой ошибке. Пользовательские
данные (`.env`, `logs/`, `output/`) больше не затрагиваются, ход установки
пишется в `_update/update.log`.

**Мелкие исправления.** Кнопки «Архивировать»/«Восстановить» в истории
файлов больше не падают (отсутствовавший импорт `shutil`); удаление и
очистка истории поиска теперь сохраняются в файл, а обрезка до 100 записей
работает; зависимости зафиксированы на проверенных версиях — CI больше не
ломается от свежих релизов библиотек; внутренняя чистка кода (pyflakes) и
новые тесты апдейтера и истории.

## [2.3.0] — Массовый обход соцсетей, журнал, темы, macOS-сборка

**Массовый обход соцсетей.** «🚀 Открыть N профилей» открывает все вкладки
сразу — синхронно, до первого `await`, поэтому попап-блокировщик больше не
съедает очередь (а если съел — честное «Открыто X из N» и «📋 Скопировать
ссылки»). Кнопка активна, пока есть непросмотренные профили.

**Журнал «Ход поиска».** Фильтры [Все · Важные · Ошибки · Технические],
сворачиваемые блоки городов, тихие метки времени, автоскролл с кнопкой
«⬇️ К последней строке», выгрузка в `.log` и копирование, объяснимый
прогресс-бар и счётчики.

**Тёмная и светлая темы.** Палитра переведена на общие токены, мягкие цвета,
контраст ≥ 4.5:1 в обеих темах, тема применяется до первой отрисовки — без
вспышки при загрузке.

**Сборка для macOS.** Приложение теперь собирается в `.app`/`.dmg` (arm64 и
x64) с подписью Developer ID и нотаризацией в CI; данные живут в
`~/Library/Application Support`, порт — 5050, приложение само открывает
браузер.

**Автоматизация.** Новый гейт `ci.yml` гоняет тесты на трёх системах для
каждого PR; Dependabot обновляет pip-зависимости и версии Actions.

**Мелкое и фиксы.** Оценка лида с разбором в подсказке, автосохранение отметок
«Просмотрено», пауза с продолжением со следующего города, сброс счётчика
токенов 2GIS при смене ключа, удалены KPI «Через taplink»/«С рейтингом»,
сортировка «#» и кнопка-дубль «⊘ Дубли».

📄 Подробности по каждому пункту — [docs/release-notes-v2.3.0.md](docs/release-notes-v2.3.0.md).
